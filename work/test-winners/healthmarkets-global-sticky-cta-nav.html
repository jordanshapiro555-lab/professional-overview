How I drove a 10.6% Agent Start lift via a global sticky CTA nav

Adding conversion-focused CTAs to a persistent global navigation bar drove a 10.6% lift in Agent Start Page visits and a 19.6% lift in Quote Start Rate across HealthMarkets

A persistent sticky nav CTA gave ready-to-convert users a direct path to the agent funnel from any page, driving a 10.6% Agent Start lift and 19.6% Quote Start lift.

Return to winners Contact me

The Challenge

Users deep in the site had no persistent access to the conversion path

Users browsing HealthMarkets content pages — product descriptions, comparison guides, FAQs — had to navigate back to specific entry points or scroll back to the top to initiate a quote or connect with an agent. Without a consistent anchor for conversion actions, users who had developed purchase intent mid-browse had no easy way to act on it. High-intent traffic was leaking at every content page because the conversion path wasn't visible. The question was whether surfacing these CTAs globally in a sticky format would close the gap between intent and action.

Hypothesis

If we add persistent sticky CTAs to the global navigation bar across all HealthMarkets pages, then Agent Start Page visits and Quote Start Rate will improve because users at any point in their browsing journey will have a clear, low-effort path to high-intent conversion actions regardless of which page they're on.

Key Insight

💡

Persistent access to conversion actions removes the "where do I go next?" friction at every step of the browsing journey. The 19.6% Quote Start Rate lift — nearly double the Agent Start lift — suggests the sticky CTAs were particularly effective at capturing users who were already comparison shopping and ready to move forward, but had no visible next step on the content page they were reading.

The resources section variant of this test showed an even more dramatic effect — a 143% Agent Start lift — confirming that the impact is amplified on high-intent content pages where users are actively in a decision-making mindset.
